# 使用說明

這是一支已經剪好的影片專案。照下面三步就能在 Premiere 打開編輯。

**不需要安裝任何程式，也不需要輸入任何指令。**

---

## 第 1 步：安裝字型

打開 `fonts/` 資料夾，裡面的檔案**每個都點兩下**，按「安裝字體」。

裝完**先關掉 Premiere 再重開**，不然它看不到新字型。

> 沒裝字型的話，畫面上的中文會變成很細的細體，看起來不對。

---

## 第 2 步：匯入影片專案

Premiere → 上方選單 `檔案` → `匯入` → 選這個資料夾裡的 **`.xml`** 檔。

匯入後，**專案面板**（左下角）會出現一個資料夾，裡面有一個序列。**點兩下**打開它。

時間軸就會出現完整的影片，全部排好了。

---

## 第 3 步：匯入字幕

字幕是分開的，要再匯一次。

Premiere → `檔案` → `匯入` → 選：

```
subtitles/master.srt
```

匯入後它會出現在**專案面板**，不會自己跑到時間軸上。

用滑鼠**把它拖到時間軸最上面**，Premiere 會自動幫你開一條字幕軌。

> 拖不上去的話：上方選單 `視窗` → `文字` → 點「字幕」分頁
> → 右下角「從檔案匯入說明性字幕」

---

## 完成，可以開始編輯了

時間軸上的軌道：

| 軌道 | 是什麼 |
|---|---|
| **V3** | 字卡（人名、關鍵字、開場大字） |
| **V2** | 疊加畫面（B-roll） |
| **V1** | 主要影片，含字卡段與片尾 |
| **A1 / A2** | 聲音，已經跟畫面綁在一起 |

拖動、剪短、調順序都可以直接做。

逐段的時間碼與台詞對照在 `TIMELINE.md`。

---

## 想改字卡上的文字？

時間軸上的字卡是影片，不能直接打字。如果這個封包附了 `mogrt/` 資料夾，
裡面就是可以改字的版本：

1. Premiere → `視窗` → `基本圖形`
2. 切到「**瀏覽**」分頁
3. 右下角「**安裝動態圖形範本**」，點它
4. 選 `mogrt/` 裡對應的檔案
5. 從面板把它**拖到時間軸**，放在原本那張卡的位置
6. 選中它，切到「**編輯**」分頁，就能打字、改顏色
7. 把被取代的舊片段刪掉

**動畫不會壞**，你只會改到文字和顏色。

---

## 常見狀況

**素材顯示「離線」/ 紅色畫面**

**點兩下 `修復素材連結.command`**，它會自動把素材位置改成你電腦上的實際位置。

跑完會開一個黑色視窗顯示結果，只要沒有紅字「找不到」就是成功了，按 Enter 關掉。
然後回 Premiere，把專案面板裡舊的序列刪掉，重新匯入一次 `.xml`。

> 第一次點兩下如果 macOS 說「無法打開，因為來自未識別的開發者」：
> 對著檔案按**右鍵** → `打開` → 再按一次`打開`。只有第一次要這樣。

還是不行的話，在 Premiere 專案面板對著紅色的素材按右鍵 → `連結媒體`
→ 指到這個資料夾裡的 `media/`。

**字幕文字太大 / 位置不對**

選中字幕，在「基本圖形 > 編輯」裡調整大小和位置。

**中文變細體**

字型沒裝好。回到第 1 步，裝完**一定要重開 Premiere**。

## 這個資料夾裡有什麼

```
開始這裡.md           ← 你正在看的這份
（專案名）.xml         ← 第 2 步匯入這個
fonts/                ← 第 1 步安裝這些
subtitles/            ← 第 3 步匯入這裡的 master.srt
mogrt/                ← 想改字卡文字時用（可能沒有）
TIMELINE.md           ← 逐段時間碼對照

修復素材連結.command  ← 只有素材離線時才點它

media/                ← 影片素材，不用動
overlays_prores/      ← 字卡動畫，不用動
_製作端/              ← 製作用的工具，跟你無關
```

`subtitles/` 裡如果有 `master-完整版.srt`，那是未過濾的版本 ——
只有在你決定不用 V3 字卡時才改用它，否則字幕會跟大字重複。
