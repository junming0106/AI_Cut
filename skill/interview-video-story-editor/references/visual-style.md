# 採訪影片視覺、轉場與字卡規範

只在任務涉及視覺設計、剪輯風格、轉場、字幕、動態字卡或實際影片製作時讀取本文件。分析模式應描述既有風格；規劃與製作模式才提出或套用設計。

## 建立視覺系統

依序檢查品牌規範、現有影片語言、題材、人物、觀眾與平台。品牌色、字體、Logo安全距離及既有模板優先於本文件的預設值。

未提供品牌規範時，使用「溫暖、可信、現代的紀錄片」預設：

- 主底色：暖白或淺灰。
- 文字：深灰、白色及一個品牌主色。
- 強調色：一個高辨識色，例如暖黃；不要同時使用多個競爭色。
- 字體：易讀的無襯線字體，標題粗體、內文正常或中等字重。
- 質感：可加入很淡的紙張、灰塵、底片顆粒或刮痕，不能降低可讀性。
- 影像：以自然膚色及真實空間為主，避免重濾鏡、過度銳化與不一致色偏。

醫療、法律、金融、公共政策或嚴肅事件應降低手作紋理及活潑動畫，改用克制、清晰的字體與轉場。

## 開場與主標題

開場可使用 3–6 個快速 B-roll、強力引言與短語字卡建立問題，再顯示主標題。

### 鉤子大字

- 每個畫面只承擔一個主要語意，通常一至兩行。
- 使用粗體無襯線，白色或暖白；重要詞可用品牌色或強調色。
- 可置中或依人物負空間對齊，不遮住眼睛、嘴部及主要動作。
- 使用淡入、短距離上移或遮罩揭露；不預設逐字彈跳。
- 開場鏡頭通常約 0.8–1.8 秒一換，但必須以讀得完及理解得了為準。

### 拼貼式主標題

- 可用兩欄或三欄呈現人物、現場及細節。
- 欄位之間保持一致間距或使用乾淨裁切，不混用多種邊框。
- 主標題應比背景資訊明顯，必要時加半透明遮罩或降低背景對比。
- 主標題停留至少足以完整讀完一次。

## 轉場語言

硬切是預設。先嘗試以內容、動作與聲音完成銜接，再考慮特效。

### 語意硬切與 Match Cut

- 在語句停頓、重音、動作完成或視線轉移時切換。
- 可利用相似動作、形狀、色彩、構圖及畫面方向銜接。
- 同一空間應維持方向感；刻意跳躍時需有明確節奏或觀點。

### 聲音轉場

- J-cut：下一場聲音先進，適合建立期待或引出新人物。
- L-cut：目前聲音延續到下一畫面，適合以 B-roll 證明正在說的內容。
- Voice bridge：讓同一訪談跨越數個 B-roll，維持敘事連續。
- 保留適量 room tone 或環境音，避免切點前後突然真空。

### 章節問題卡

用於主題明顯轉折，不用於每一題普通問答。

- 暖白或淺灰全畫面背景。
- 中央放中文問題，第二行可放較小且低對比的英文或補充文字。
- 可加極淡紙張、灰塵、刮痕或底片閃爍。
- 先讓問題清楚出現，再讓紋理略微變化。
- 可用硬切、短淡白或下一段聲音先行離場。
- 停留時間通常約 1.5–3 秒，以自然讀完為準。

### 疊化

只在回憶、時間流逝、成果累積、照片或情緒逐漸收束時使用。一般對話切換不用疊化。普通疊化短而自然；回憶或照片可稍長，但不能拖慢語句。

### 遮擋與動作轉場

素材中已有前景人物、門框、螢幕、物件或快速鏡頭移動時，可利用自然遮擋銜接。不要為套效果而製造與原素材方向不符的假運鏡。

### 淡白與淡黑

- 淡白：希望、溫暖、成長、品牌使命及正向結尾。
- 淡黑：沉思、嚴肅議題、時間中斷或傳統結束。

### 限制

- 一支影片選擇一套主要轉場語言。
- 不為每次換鏡加入不同效果。
- 炫光、故障、旋轉、強烈縮放、快速甩鏡及速度拉伸，只有品牌與素材本身支持時才使用。
- 明顯轉場必須對應段落、時間、地點或情緒變化。

## 字卡系統

### 人物姓名條

- 第一行為姓名或稱呼；第二行為職稱、年資或專業身分。
- 放在人物視線反方向的負空間及安全區。
- 使用淡入加短距離水平位移或簡單遮罩展開。
- 停留到能完整讀完；同一人物不反覆顯示。

### 問題字卡

- 可使用全畫面章節卡或疊加在訪談畫面。
- 中文問題為主要層級，翻譯或補充為次要層級。
- 不與逐字字幕、姓名條及人物臉部重疊。
- 問題出現時，減少其他競爭資訊。

### 資訊標籤

用於方法、計畫、課程、案例或成果：

- 左側可用品牌色標籤，右側接暖白說明條。
- 標題使用粗體，說明控制在一至兩行。
- 使用短滑入、淡入或遮罩展開。
- 資訊過多時拆成數張，不縮到難以閱讀。

### 關鍵字大字

- 每個鏡頭只呈現一個主要詞語。
- 一組概念通常控制在三至五項。
- 使用強調色並加深色描邊、陰影或底板。
- 每個關鍵字搭配不同且語意相符的 B-roll。
- 使用淡入、輕微縮放或上移；避免彈跳、旋轉與亂序逐字動畫。

### 引言與數據卡

- 引言保持原句或清楚標示節錄。
- 數據必須可驗證並保留來源。
- 數字為主要層級，說明及來源為次要層級。
- 不放大缺乏敘事意義的數字。

### 片尾字卡

建議分階段出現：

1. 品牌主張或情感總結。
2. 次要翻譯或補充文字。
3. Logo。
4. 必要時加入 CTA。

不要把標語、Logo、網址、電話、QR Code及社群帳號同時堆在中央。依用途保留真正需要的資訊。

## 文字動畫

- 優先使用淡入、短距離位移、遮罩揭露及輕微縮放。
- 一般進退場約 0.25–0.6 秒；標題可稍慢，關鍵字可稍快。
- 進場多使用自然 ease-out，退場使用 ease-in 或直接乾淨切除。
- 文字依語意單位出現，不預設逐字動畫。
- 動畫完成後保留足夠閱讀時間。
- 同一資訊層級使用一致的方向、速度及緩動。
- 避免連續閃爍、過度回彈、高速旋轉及無意義循環。

## 字幕

- 每次最多兩行，依自然語意斷句。
- 放在畫面下方安全區，不貼邊，也不遮擋重要手勢與作品。
- 預設使用白字、深色描邊或陰影；複雜及明亮背景加半透明底板。
- 字幕可讀性優先於裝飾風格。
- 字幕、姓名條、問題卡及資訊標籤不得互相重疊。
- 雙語字幕只在觀眾或發布需求明確時使用，避免同時顯示過多行。

## 視覺交付摘要

規劃或製作模式需附上簡短 style recipe：

| 項目 | 應說明內容 |
|---|---|
| 整體調性 | 溫暖、克制、活潑、權威等 |
| 色彩 | 主色、輔色、強調色及背景色 |
| 字體層級 | 主標、問題、姓名、內文、字幕 |
| 轉場語言 | 硬切、聲音橋、章節卡、疊化等 |
| 動畫 | 方向、速度、緩動與禁用效果 |
| 質感 | 紙張、顆粒、陰影、圓角或無紋理 |
| 片尾 | 標語、Logo、CTA及停留時間 |

## 視覺檢查

- 膚色自然，跨鏡頭白平衡與曝光沒有明顯跳動。
- 主標、問題、姓名、資訊、字幕的層級一眼可辨。
- 明暗及複雜背景下仍可閱讀。
- 字卡不遮擋眼睛、嘴部、手勢、作品或關鍵動作。
- 轉場、字卡及動畫符合題材，且全片保持一致。
- Logo比例、留白、色彩及安全距離符合品牌規範。
